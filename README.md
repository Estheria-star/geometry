# 几何工坊 · Geometry Studio

📐 **在线使用 → https://geometry.startian.top/**

> 面向高中数学教学的平面几何 × 立体几何可视化工作台：表达式实时绘制、向量关系自动判定、面积体积二面角一键求解、AI 出图（DeepSeek）。单文件约 530 KB、零依赖、离线可用。

## 功能一览

**平面几何**

- 函数与方程同绘：显式 `y=f(x)`、隐式 `F(x,y)=0`、极坐标 `r=f(θ)`、参数方程、虚数模式 `e^(i*t)`
- 隐式乘法：`2x`、`3sin(x)`、`πr` 可直接输入
- mini-CAS 求导（幂函数/和差积商/链式法则自动应用，结果数值校验）、单调性与极值分析、切线、弦长
- 圆锥曲线分析：焦点 / 准线 / 离心率 / 渐近线一键求
- 向量关系自动判定（垂直 / 平行 / 相交 / 重合 / 异面）+ 面积推导步骤
- 一元 / 二元不等式解集与区域填充

**立体几何**

- 空间点 / 线段 / 直线 / 平面自由构建，拖拽即改
- 拉伸体（棱柱 / 棱锥 / 圆柱 / 圆锥 / 球…）、组合立体（封闭校验 + 体积）
- 外接球 / 内切球（自动找球心并验证「所有顶点在球面上」）
- 线线 / 线面 / 面面距离、二面角（含图解步骤）
- 三视图、横截面、体积 / 表面积一键求

**交互与工具**

- 点选多点连线 / 定平面 / 建系（图形变换：移原点 + 旋转对齐）
- 参数滑块实时联动（参数为 `a b c d f g h k` 共 8 个，范围默认 [-10,10]，可自定义步幅）
- 预设场景、导入导出、涂鸦批注层、纯净模式（全屏）、只读模式、PNG 导出
- **语音输入**：数学口述规范化（「三x平方」→ `3x^2`），支持追加 / 替换
- **AI 出图**：接入 DeepSeek，题目 → 自动分析 → 自动建造图形与解析卡（Key 仅存本机浏览器，直连官方接口）
- 暗色 / 亮色主题，适配课堂投影与手机

## 技术说明

- **纯前端单文件**（约 530 KB）：表达式解析器 / 编译器 / 渲染管线全部自研，零依赖
- AI 出图走 DeepSeek API（`api.deepseek.com`），CSP 仅放行该域；Key 只存 localStorage
- 本目录为构建产物；源码为 `src/` 分片 + `build.py`
- 属于「星恬的小站」旗舰作品之一
